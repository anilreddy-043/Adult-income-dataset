# 📊 Adult Income Dataset Analysis

## 📌 Project Overview

The **Adult Income Dataset Analysis** project focuses on analyzing demographic and employment-related information to understand the factors influencing an individual's income.

The project uses Python and data analysis techniques to explore the dataset, identify patterns, visualize relationships, and build machine learning models to predict whether an individual's annual income exceeds $50K.

## 🎯 Project Objectives

- Analyze demographic and socioeconomic information.
- Perform data cleaning and preprocessing.
- Handle missing values and duplicate records.
- Conduct Exploratory Data Analysis (EDA).
- Identify important factors influencing income.
- Visualize income distribution and feature relationships.
- Build machine learning models for income classification.

## 📂 Dataset Description

The Adult Income Dataset contains information about individuals, including:

| Feature | Description |
|---|---|
| Age | Age of the individual |
| Workclass | Type of employment |
| Education | Education level |
| Education-num | Years of education |
| Marital-status | Marital status |
| Occupation | Type of occupation |
| Relationship | Relationship status |
| Race | Race category |
| Sex | Gender |
| Capital-gain | Capital gains |
| Capital-loss | Capital losses |
| Hours-per-week | Working hours per week |
| Native-country | Country of origin |
| Income | Income category (<=50K or >50K) |
